# shadcn dashboard (Next.js) for pg-bloat-detective.

## Data flow

The page is fully static — it reads `src/app/dashboard/data.json`, generated by the CLI:

```bash
# from repo root
.venv/bin/python -m bloatdetective report --db timeline.db --json --out dashboard/src/app/dashboard/data.json
```

## Dev

```bash
npm install
npm run dev     # -> /dashboard
npm run build   # verify
```
